# Anti-Counterfeiting Page Clone & Customization Guide

لقد قمنا بنسخ الصفحة بالكامل وحفظها في هذا المجلد بشكل منظم ومنسق لتتمكن من تعديلها بسهولة.

## هيكل الملفات (File Structure)

- **`index.html`**: الصفحة الرئيسية التي تحتوي على الهيكل الكامل (Header, Verification Form, Page Content, Footer, Age verification popup).
- **`css/`**: المجلد الخاص بملفات التنسيق (Stylesheets):
  - `css/antifake.css`: ملف التنسيق الخاص بنموذج التحقق (Verification Box) ونافذة النتائج المنبثقة (Success/Warning Popups).
  - `css/post-5100.css`: ملف التنسيق المخصص لهيكل الصفحة وهوامشها واستجابتها للهواتف والشاشات المختلفة (Elementor Styling).
  - `css/points.css`: ملف التنسيق الخاص بنظام النقاط.
- **`js/`**: المجلد الخاص بملفات الجافا سكريبت (Scripts):
  - `js/antifake.js`: الملف الأساسي الذي يحتوي على منطق التحقق (Verification Logic) والـ Captcha وقراءة الـ QR Code وإرسال تقارير الغش.
  - `js/points.js`: كود إدارة النقاط المكتسبة.
  - `js/welcome.js`: كود النافذة الترحيبية.

## كيفية البدء والتعديل (How to Modify)

### 1. تشغيل الصفحة محلياً
يمكنك فتح ملف `index.html` مباشرة في أي متصفح، ولكن لتفادي قيود الحماية في بعض المتصفحات عند استدعاء أكواد الجافا سكريبت الخارجية، يفضل تشغيلها عبر خادم محلي (Local Server):
- إذا كنت تستخدم **VS Code**، يمكنك تثبيت إضافة **Live Server** والضغط على **Go Live**.
- أو تشغيل خادم سريع عبر الـ Terminal باستخدام Python:
  ```bash
  python -m http.server 8000
  ```
  ثم فتح الرابط: `http://localhost:8000`

### 2. تعديل النصوص والألوان
- **تغيير الألوان والهوامش**: يمكنك تعديل الألوان العامة ونموذج التحقق من خلال ملف `css/antifake.css`.
- **تعديل النصوص والشعارات**: ابحث في ملف `index.html` عن النصوص التي تود تغييرها (مثل: "Anti-Fraud Inquiries" أو "Verify Your Products") وقم بتعديلها مباشرة.

### 3. تعديل منطق التحقق (Verification Logic)
إذا أردت ربط نموذج التحقق بقاعدة بياناتك الخاصة أو خادمك الخاص:
- افتح ملف `js/antifake.js` وابحث عن دالة `searchCode()`.
- ستجد أن الكود يقوم بإرسال طلب (GET Request) إلى الرابط: `https://wp.asy315.vip/one/v1/w/query/open` (وهو السيرفر الافتراضي الخاص بـ Tokyo Ejuice). يمكنك استبداله برابط الـ API الخاص بك.
- نموذج إرسال بلاغات التقليد (`myForm`) يقوم بإرسال البيانات إلى: `https://antifake-service.tokyoejuice.com/antifake/antifake`. يمكنك تعديل سمة `action` الخاصة بالنموذج في ملف `index.html` لتوجهها لسيرفرك الخاص.

## مميزات هذا الكلون (Features of this Cloned Page)
1. **أداء ممتاز وغير معتمد على الإضافات**: تم تحويل جميع الصور التي كانت تعمل بخاصية التحميل الكسول (Lazy Load) لتعمل بشكل مباشر (`src` عادي)، لضمان ظهور الصور فوراً وبدون الحاجة لـ WordPress.
2. **روابط محلية بالكامل**: تم فصل ملفات التنسيق البرمجية الخاصة بصفحة التحقق محلياً وتعديل مساراتها في ملف `index.html` لتتمكن من تحريرها وتغيير الاستايل بالكامل دون التأثير على باقي الصفحة.
3. **تجاوب كامل**: الصفحة تدعم التصفح من الجوال والتابلت والكمبيوتر بنفس المظهر والجودة الأصلية.
